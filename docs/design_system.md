# Design System

## Typography
- Heading: Merriweather, serif (`font-heading`)
- Body: Inter, sans-serif (`font-body`)
- Caption: JetBrains Mono (`font-caption`)
- Data: Space Mono (`font-data`)

## Colors
- Primary: #FABF2C (Gold/Yellow)
- Background: #000000
- Card/Surface: #0a0a0a
- Border: #1a1a1a
- Success: #00d672
- Error: #ff4757

## Patterns
- Brutalist/Terminal Aesthetic: Heavy use of uppercase, tracking (letter-spacing), monospace fonts, sharp borders, and high contrast.
