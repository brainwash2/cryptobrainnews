## Observations Log

### Phase E – Chart Standardisation (2026‑04‑30)
- **PI‑symbol error:** TradingView Lightweight Charts `HistogramSeries` does not accept categorical time values (e.g., coin symbols like "PI"). This broke the Top Movers, Market Cap Dominance, and Exchange Volume Dominance charts on `/data/markets/spot`. **Fix:** Those three histograms were reverted to Recharts `BarChart` (mounted guard + `isAnimationActive={false}`). BTC/ETH price area charts kept as Lightweight.
- **lineWidth type error:** Lightweight Charts v5 restricts `lineWidth` to `1 | 2 | 3 | 4`. `FuturesClient` and `DeFiTvlClient` used `1.5`, causing TypeScript errors. Fixed to `2`.
- **Unused imports:** `ISeriesApi` in `FuturesClient`, `IChartApi` in `RevenueTrendClient` and `StablecoinUsdClient`, `fmtUsd` in `DeFiTvlClient` — all removed.

### Phase D – Dune API Integration (2026‑04‑29)
1. **Execution safety:** `executeDuneQuery` mirrors the Dune safety plan exactly — cached results first, then execute‑fresh with a 30‑second polling loop, 45‑second timeout, and graceful seed fallback. Maximum 9 fresh calls/day.
2. **Seed freshness:** Seed arrays are accurate April‑2026 snapshots. Require manual refresh every quarter if Dune remains unavailable long‑term.
3. **Token unlocks:** Query 10 routed to DefiLlama `/unlocks` instead of Dune community dataset.
4. **Environment coupling:** All 9 query IDs read from env vars. Module compiles without them and serves seed data.

### Zerion Integration (2026‑04‑30)
- Created `src/lib/zerion.ts` using Zerion free tier (2,000 req/month). Queries known whale addresses (Binance, Coinbase, Kraken, Maker DAO). Filters >$100K and deduplicates by tx_hash.
- Whale‑watch page merges Etherscan + Zerion. New "Entity" column shows Zerion labels. Source column distinguishes `etherscan` from `zerion`.
- **Note:** Zerion `Authorization` header uses `Basic` auth with `Buffer.from()`, requiring Node.js runtime. Module has `import 'server-only'` which is correct, but whale‑watch page must NOT be set to `runtime = 'edge'`.
